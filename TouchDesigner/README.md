# TouchDesigner example

`laserBase.toe` is a minimal TouchDesigner example scene for Etherhaze.

1. Start Etherhaze with `npm start`.
2. Open `laserBase.toe` in TouchDesigner.
3. The scene sends its laser stream to Etherhaze on `127.0.0.1:7765`.

Use it as a starting point for laser shapes, palettes, MIDI control, and audio-reactive effects.

> This project file is for simulation and development. Before using any design with physical laser hardware, validate the installation with qualified laser-safety professionals.
